# FactPack 1.1 Implementation Plan (post-ORCL improvements)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the five information gaps the Oracle comparison exposed — leverage and capital-return fields the capture already holds, the earnings press release (8-K exhibit 99.1), the cover-page share count, the latest 10-K's risk factors alongside a 10-Q, and judgment-selected highlight cells — then regenerate Oracle's report.

**Architecture:** The FactPack moves to 1.1.0 with additive fields. `facts:prepare` fetches two more EDGAR documents by code (keyless): the earnings 8-K's exhibit 99.1 and, for a 10-Q, the latest 10-K primary document. Mappers gain the new fields; the projection gains rows and a set of fact-built highlight cells; the Judgment contract lets the model pick up to four highlight keys, which the merge turns into snapshot cells. Nothing in the render layer changes.

**Tech Stack:** TypeScript, Zod 4, Vitest 5, `tsx` CLIs, the existing `lib/edgar`, `lib/facts`, `lib/synth`. No new runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-09-12-fact-pipeline-design.md` (Revision 2, appended by Task 6) and `docs/superpowers/specs/2026-09-13-synthesis-design.md` (Highlight cells, appended by Task 6). Until Task 6 lands, this plan's Global Constraints are the binding text.

## Global Constraints

- **Numbers are numbers; ratios are decimals.** New `ttm` fields are decimals or multiples exactly as the vendor reports them (`interest_coverage` 4.57 stays 4.57; `free_cash_flow_yield` −0.066 stays a ratio).
- **Raw captures are verbatim and never hand-edited.** New EDGAR documents are saved byte-for-byte; `facts:prepare` skips a file that already exists.
- **FactPack schema is 1.1.0; every change is additive.** `lib/facts/schema.ts` is this plan's to change; `lib/report.schema.ts`, `lib/format.ts`, `lib/validate.ts` stay frozen. The 16 standard snapshot cells and their order are unchanged; highlight cells are appended after them.
- **Grounding surface = the prompt's Facts and Context blocks + the judgment's own calls.** Every new fact the prompt renders passes through `lib/format.ts`.
- **All network I/O stays in `lib/edgar/` and `lib/prices/yahoo.ts`**, with `fetchImpl` injectable; `lib/facts/` and `lib/synth/` do no I/O.
- **The manifest↔mapper closure test stays green**: every captured file is read by a mapper (phase inputs aside); optional files are declared as such.
- **Test output pristine; `npx tsc --noEmit -p .` clean; `npx eslint lib scripts` clean; `npm run build` green after Task 7.** Commit after every task with the `Co-Authored-By:` and `Claude-Session:` trailers.

```ts
export interface RecentFiling { form: string; accession: string; filedDate: string; periodEnd: string; primaryDocument: string; items: string[] }
interface RecentBody { filings: { recent: SubmissionsBody["filings"]["recent"] & { items?: string[] } } }

export function parseRecent(body: RecentBody): RecentFiling[] {
  const r = body.filings.recent;
  return r.form.map((form, i) => ({
    form, accession: r.accessionNumber[i], filedDate: r.filingDate[i], periodEnd: r.reportDate[i],
    primaryDocument: r.primaryDocument[i], items: (r.items?.[i] ?? "").split(",").map((s) => s.trim()).filter(Boolean),
  }));
}
export const findEarningsRelease = (recent: RecentFiling[], filedOnOrBefore: string) =>
  recent.find((f) => f.form === "8-K" && f.items.includes("2.02") && f.filedDate <= filedOnOrBefore) ?? null;
export const findLatestAnnual = (recent: RecentFiling[], filedOnOrBefore: string) =>
  recent.find((f) => f.form === "10-K" && f.filedDate <= filedOnOrBefore) ?? null;

const indexUrl = (cik: number, accession: string) => `https://www.sec.gov/Archives/edgar/data/${cik}/${accession.replace(/-/g, "")}/index.json`;
export async function fetchFilingIndex(cik: number, accession: string, contact: string, fetchImpl: FetchLike = fetch): Promise<{ name: string }[]> {
  const j = await edgarJson<{ directory: { item: { name: string }[] } }>(indexUrl(cik, accession), contact, fetchImpl);
  return j.directory.item;
}
export function exhibit99Url(cik: number, accession: string, items: { name: string }[]): string | null {
  const hit = items.find((i) => /ex[-_]?99/i.test(i.name) && /\.htm/i.test(i.name));
  return hit ? filingUrl(cik, accession, hit.name) : null;
}
export async function fetchRecent(cik: number, contact: string, fetchImpl: FetchLike = fetch): Promise<RecentFiling[]> {
  return parseRecent(await edgarJson<RecentBody>(submissionsUrl(cik), contact, fetchImpl));
}
```

```ts
// filing-text.ts
export const PRESS_CAP = 16000; // an earnings release is ~30k chars; the headline metrics are in the first half
const COVER_RE = [
  /outstanding\s+as\s+of\s+[A-Za-z]+\s+\d{1,2},\s+\d{4}[^0-9]{0,40}?(\d{1,3}(?:,\d{3}){2,3})/i,
  /had\s+(\d{1,3}(?:,\d{3}){2,3})\s+shares[^.]{0,80}?outstanding/i,
  /(\d{1,3}(?:,\d{3}){2,3})\s+shares\s+of[^.]{0,80}?outstanding/i,
];
export function extractCoverShares(text: string): number | null {
  const head = text.slice(0, 30000);
  for (const re of COVER_RE) { const m = re.exec(head); if (m) { const n = Number(m[1].replace(/,/g, "")); if (n >= 1e8) return n; } }
  return null;
}
```
